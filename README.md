# НЕВДАХИНЪ — Семейная ремесленная мануфактура

Официальный сайт и интернет-лавка домашней крафтовой продукции:
- Консервы и тушенка
- Заготовки, соусы и соления
- Копченые деликатесы (грудинка, ребра, курица)
- Колбасные изделия (краковская, сервелат, сосиски, докторская, ветчина)
- Заморозка и полуфабрикаты (пельмени, хинкали, голубцы)
